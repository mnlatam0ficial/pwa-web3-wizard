# Asset Protocol Console

PWA mínima de control.

## Uso rápido

1. Compila `contracts/DigitalAssetToken.sol` en Remix (OpenZeppelin).
2. Copia el **Bytecode** completo y pégalo en `js/contracts-repo.js` (campo `bytecode`).
3. Sube toda la carpeta a GitHub Pages.
4. Abre en el móvil → Conectar Wallet → Desplegar → Activar Protocolo.

## Botones

- **Desplegar Contrato** → crea el token (arranca pausado)
- **Activar Protocolo** → abre el trading
- **Pausar Protocolo** → vuelve a cerrar
- **Ajustar Fee** → deja 2.5% / 8%
- **Eximir mi dirección** → te añade a la lista de exentos
